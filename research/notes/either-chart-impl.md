This isolated implementation follows reviewed lexical certificate plan 7c9b137.
Legacy is the default (`EitherLegacyDisabled`); only explicit
`EitherSurfaceInclusiveV1` reserves literal either and mints the actual selected
lexical identity origin. No model, corpus, or benchmark run was used.

The private pending/left/pair certificate retains source, offered category,
features, token indices, source spans and operand provenance. Only direct
application then explicit OR coordination completes the local certificate.
Pending composition/unary/root escapes fail closed. Paired application uses the
checked occurrence kernel and actual coordination child layout; only the final
full-clause period is supported punctuation. Operand punctuation is rejected
before activation, including punctuation silently absorbed by ordinary grammar.

transport; ordinary packing ignores that state. Active packing retains path,
mode and source certificate. `pairedOrOrigins` distinguishes ordinary roots,
invalid/pending carriers and validated exact normalized root snapshots.

## Pre-measurement availability and hard stops

The two new frozen208 targets are `either-inclusive-authored-1` (Mira is either
quiet or tall.) and `either-inclusive-authored-2` (Noel is either young or red.).
The sealed expanded208-baseline observations contain parse/DRS responses, not

categories. Neither artifact establishes availability or absence of the exact

hand-specified X/X is not a trained model fact. Prediction: default all208
responses must stay unchanged; enabled gains depend on the actual lexical and
source-pair gates and are not promised. Unsupported nested pairs, commas and
explicit XOR tails must abstain; no exclusive-gold reinterpretation is allowed.

## Reviewed hardening

Review found the initial punctuation blacklist too narrow. Pending operands and
ordinary operands imported into active application now exclude every nonempty
source token consisting entirely of Unicode punctuation/symbols. Mixed lexical
hyphens/apostrophes remain eligible. Actual offered/lexical witnesses exercise
parentheses and ellipsis; existing lexical dispatch does not interpret standalone
hyphen/bracket offers, so those controls are explicitly absence controls, not
claimed proof of the new boundary. The default route does not inspect this gate.
`OrOrigin` is now abstract with read-only accessors. Actual selected either
leaves enter kernel PairedPending immediately, so an attempted unary downgrade
fails in the kernel as well as the chart guard.

The expanded test invokes GHCi against the real private lexical producer and
combinator implementation without exposing constructors. It checks successful
producer pairing, every alternative combinator, missing payload/OR origin,
foreign provenance, altered category/index, identical terms without authority,
packing distinctions, and actual type-raising downgrade rejection. Public
checks include case variants, a mixed-hyphen predicate, matched complete/missing
source-pair sets, punctuation-envelope attacks and all retained root meanings.
